網頁｜打開模型研究頁面

三個步驟打開網頁

1

啟動後端（API，埠 8900）

cd E:\程式碼\ERP_HMM_Project\k_core\backend
.\.venv\Scripts\python.exe -m uvicorn kcore.main:app --port 8900

2

啟動前端（網頁，埠 5174）

cd E:\程式碼\ERP_HMM_Project\k_core\frontend
npm run dev

3

用瀏覽器開啟，第一個分頁就是「模型研究」

http://localhost:5174/#case/CVFLOW

程式更新後要重新啟動後端；畫面若顯示「找不到這項功能的 API」，就是後端還是舊版。

網址最後的 #case/CVFLOW 會直接打開 CVFLOW 案例，也可以從右上角的「場域案例」選單切換。其他三個分頁（轉換與審核、原始文件、轉換設定）是給「用本地 LLM 整理原始資料」用的，這次的 CVflow 資料不經過它們。
