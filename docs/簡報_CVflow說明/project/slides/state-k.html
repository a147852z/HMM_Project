狀態名稱只是中性編號 H0、H1。代表什麼意思，是訓練完之後看它們的內容再解讀的。

長條長度只用來比較大小，座標從 3,000 起算（不是從 0），重點是 K=2 的 BIC 最低。若每個 AI 模型分開訓練，資料太少，BIC 幾乎都選 K=1；五個模型合併後，資料量才足以支持 2 個狀態。
